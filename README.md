# ApexCare Safe Mode

أداة PowerShell بسيطة لتشخيص جهاز Windows بأقل صلاحيات ممكنة. الوضع الافتراضي **للقراءة فقط** ولا يغيّر إعدادات النظام.

## ما الذي يفعله؟

- يعرض معلومات الجهاز، النظام، المعالج، كرت الشاشة، الأقراص والبطارية.
- ينشئ تقريرًا محليًا في `%ProgramData%\ApexCare\SystemReport.txt`.
- يعرض روابط دعم الشركة المصنّعة فقط؛ لا يثبت تعريفات أو برامج.
- يوفر فحص Microsoft Defender السريع عند اختياره يدويًا.
- يتضمن خيارًا منفصلًا لتطبيق إعدادات RPC للطابعات بعد تأكيد نصي صريح؛ هذا الخيار يغيّر Registry ويتطلب إعادة تشغيل يدوية.

## ما الذي لا يفعله؟

- لا يستخدم `irm ... | iex` ولا ينزّل كودًا من الإنترنت.
- يطلب Administrator عبر نافذة UAC عند التشغيل، لكن الرفع لا يفعّل أي صيانة خطرة.
- لا يغيّر Registry أو خطة الطاقة أو إعدادات الشبكة أو الرسوميات تلقائيًا. إعدادات RPC هي الاستثناء الوحيد، ولا تعمل إلا من خيار مستقل وبعد تأكيد `APPLY-RPC-SETTINGS`.
- لا يعطّل خدمات Windows، ولا يحذف ملفات، ولا يثبت حزمًا.
- لا ينشئ `RunOnce`، ولا يعيد تشغيل الجهاز، ولا يستأنف عملًا مخفيًا بعد الإقلاع.

## التشغيل

شغّل الملف المحلي بعد مراجعته:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\ApexCare.ps1
```

يمكن تشغيله من نافذة PowerShell عادية؛ سيظهر طلب UAC مرة واحدة لتشغيل النسخة المرتفعة. رفض الطلب ينهي الجلسة.

> لا تشغّل أوامر تنزيل وتنفيذ مباشرة من الإنترنت مثل `irm URL | iex`. نزّل الملف من مصدر تثق به، راجعه، ثم شغّله محليًا.
